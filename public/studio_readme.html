📖 產品定位與設計初衷

Portable Studio 是專為「TOEIC 速記 PWA」打造的輔助審計工作台。它的核心使命是：

  • 隨身便攜（Portable）：無論在筆電、平板或手機上，隨時隨地檢視 5 大題庫的 v4 故事板提示詞與考點例句。
  • 直觀審計（Visual QA）：即時查看哪些單字已成功生成圖片、哪些單字尚待出圖，杜絕缺圖或錯圖。
  • 外出協作與手動貼圖（Paste & Pack ZIP）：在外用網頁版 Gemini 生圖時，可直接複製圖片貼上暫存，一鍵打包下載 ZIP 檔帶回本機入庫。
  • 雲端進度同步（Supabase Real-time Sync）：透過極輕量純文字中繼站，追蹤自動管線與手動出圖的完工標記與時間戳。

🌟 核心功能特色

1. 雙頁籤進度過濾器 (Dual-Tab Filter)

• 🔵 待出圖清單 (Pending)：即時篩選出尚未落盤的單字，按鈕直接顯示剩餘待補數量。
• 🟢 已完工檢視 (Completed)：檢視所有已驗證完工的單字卡片與生成成果。

2. 五大題庫切換與 Z➔A 逆向錯開 (Tier & Sorting)

支援 Core 1200、Advanced 2500、Expert High Part 1/2/3 自由切換。
提供 Z ➔ A 逆序模式：外出用手機手動生圖時，與本機背景自動管線（A ➔ Z）雙向對開、兩端合圍，絕不撞題重複花費。

3. 工作台專注檢視區 (Workbench)

• 顯示單字標題、詞性（POS）、多益情境中譯、產業領域主題標籤。
• 多益具象考點句（字體放大 2 號 + 專屬情境中譯）。
• 🎨 1:1 發光看板概念插畫 Prompt：點擊「📋 複製生圖 Prompt」一鍵複製至剪貼簿。

4. 剪貼簿極速貼圖與打包 (Paste Zone & ZIP Export)

• 在 Gemini 網頁版產出圖後，直接按 Ctrl + V 或長按貼上。
• 點擊 📦 一鍵打包下載 ZIP，整批下載為標準命名的 ZIP 檔，帶回本機解壓縮直接入庫！

🛠️ 本機同步與發布指令

生圖任務結束後，在專案終端機執行下列指令，即可同步圖檔並推播至線上網址：

# 1. 自動校準伴侶程式題庫與圖片標記
python scripts/sync_portable_dataset.py

# 2. 打包建置並推送到 Vercel 上線
cmd.exe /c "npm run build"
git add public/portable_studio.html dist/portable_studio.html
git commit -m "feat(studio): sync latest dataset and image status"
git push origin main
